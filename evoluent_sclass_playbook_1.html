⚙️ X-MOUSE CONFIGURATION GUIDE

Setting Up "Simulated Keys"

  1. Open X-Mouse Button Control
  2. Select your mouse from the device list
  3. Click on a button (e.g., Button 4)
  4. Choose "Simulated Keys" from the dropdown
  5. Enter the hotkey combination (e.g., {WIN}{SHIFT}s or {CTRL}{ALT}b)
  6. Repeat for all buttons
  7. Click "Apply"

Creating Application-Specific Profiles

Pro Tip: Create different button layouts for different programs:

  • Airtable Profile: Focus on data entry & record navigation
  • Development Profile: Browser refresh, dev tools, tab switching
  • Trading Profile: Chart navigation, order execution shortcuts

X-Mouse automatically switches profiles when you focus different windows!

Exporting for Team Deployment

  1. Click "Settings" tab
  2. Select "Export"
  3. Save as KingsKey_SClass.xmbcs
  4. Share file with employees
  5. They import it: Settings → Import → Select file

🔧 TROUBLESHOOTING

Issue: Buttons "Forget" Their Functions After Windows Update

Solution:

  1. Uninstall Evoluent Mouse Manager
  2. Restart computer
  3. Open regedit (exercise caution!)
  4. Navigate to: Computer\HKEY_CURRENT_USER\Software\Evoluent
  5. Right-click Evoluent folder → Delete
  6. Close regedit
  7. Reinstall Mouse Manager or switch to X-Mouse permanently

Issue: AutoHotkey Script Doesn't Start

Solution:

  • Verify you installed AutoHotkey v2.0 (not v1.1)
  • Right-click the .ahk file → Properties → Unblock (if present)
  • Run as Administrator if needed
  • Check for syntax errors in script (missing brackets, quotes)

Issue: Webhook Not Triggering Airtable

Solution:

  • Verify webhook URL is correct (copy directly from Airtable Automation)
  • Test webhook manually using Postman or browser
  • Check that automation is turned ON in Airtable
  • Verify firewall isn't blocking outbound connections
